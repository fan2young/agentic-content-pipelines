# Visual Direction Lock

Use this gate before authoring the full animation composition. It prevents technical QA from substituting for channel-fit review.

## Required inputs

- `brand-references.json` generated by `discover_recent_video_references.py`.
- The copied `DESIGN.md` and representative style frames for up to the latest three available episodes.
- The current episode's approved narration, timing, sources, and visual mechanism plan.

Do not claim that no recent episodes exist unless the discovery script reports zero. Never discover sibling projects ad hoc from the visual task; consume only the bounded copied references in the verified handoff.

## Channel core

Treat these as the default channel identity, not optional episode decoration:

- Warm paper, ink black, off-white, and signal red form the default palette balance.
- Use the project's approved brand lockup in the opening and at least one later brand beat. A small persistent mark cannot be the entire episode identity.
- Use the red coordinate axis and origin as explanatory motion grammar.
- Preserve an editorial/print material language: publication typography, paper, dossier, receipt, annotation, physical offset, or another clearly editorial carrier.
- Prefer a publication-style Chinese headline face. A pure geometric sans/monospace technical interface requires an explicit episode-specific reason.
- Keep evidence and mechanism legible, but do not let dashboards, HUDs, generic AI-dark themes, or software panels become the dominant visual world.

Innovation happens inside this core. The anti-repetition rule may change the episode metaphor, mechanism, scene choreography, and palette balance; it must not discard the channel core merely to look different.

## Three-frame review

Create exactly three representative stills before full animation:

1. Opening: the hook, complete brand identity, and default material language.
2. Core mechanism: the hardest explanatory relationship.
3. Close: the conclusion or audience decision without template UI.

Present them beside the recent reference frames. Write one short comparison covering palette, typography, logo treatment, material language, density, and motion grammar. If the direction departs from the channel core, state why the episode requires it.

Only the user may approve `visual-direction-proof.json`. `model:auto` is forbidden at this gate. After approval, preserve the approved direction unless a later user request explicitly changes it.
