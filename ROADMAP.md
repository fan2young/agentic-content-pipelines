# Roadmap

## v0.1 — auditable foundation

- [x] Multi-stage context isolation and bounded handoffs
- [x] SHA-256 binding for authoritative audio and runtime artifacts
- [x] Explicit content, voice, visual-direction, and release approvals
- [x] Deterministic workflow and security regression tests
- [x] Threat model, security policy, and public CI

## v0.2 — portable installation

- [ ] Test the documented install path on a second machine
- [ ] Add a provider-neutral narration adapter contract
- [ ] Publish a minimal example project with synthetic media
- [ ] Add dependency and runtime provenance reports to CI artifacts
- [ ] Expand path, symlink, provider-host, and malformed-handoff tests

## v0.3 — additional reference workflows

- [ ] Extract reusable stage, handoff, and approval primitives
- [ ] Evaluate a generic article-production skill after removing brand and private-skill dependencies
- [ ] Document extension points for renderers, transcription engines, and publishing adapters

The roadmap describes intent, not a compatibility promise. Security and integrity fixes take priority over new adapters.
